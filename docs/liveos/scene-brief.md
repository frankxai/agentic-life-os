# LiveOS Today Scene Brief

## Outcome contract

- **Audience:** a high-agency private operator who wants to return to meaningful practice rather than manage another generic dashboard.
- **Surface:** the private `/today` cockpit inside `apps/liveos`.
- **First read:** “I can choose one deliberate practice, leave an honest trace, and return to it later without exposing my private life.”
- **Evidence:** the real action receipt, practice source context, reflection field, safety boundary, and Palace-anchor count.
- **Acceptance:** a static desktop/mobile product loop that is usable without motion, keyboard accessible, privacy-explicit, and visually inspected before release.

## Direction board

- **Keep:** calm operational density, source visibility, reversible action, large editorial first read, quiet space.
- **Avoid:** spiritual-guru copy, fake data, decorative space imagery, generic purple gradients, fake glass card stacks, unearned 3D, and all-caps UI text.
- **Signature:** a code-rendered practice map that changes as the operator advances from intention through review.
- **System:** dark green-black operational base, restrained mint signal, warm boundary notes, technical sans for controls, editorial serif for the first read, CSS-only local state feedback, reduced-motion-safe behavior.
- **Asset tier:** Tier C code-authored exact product UI and stateful practice map. No external, generated, or third-party assets are used.

## Motion

The only movement is fast local button feedback and state emphasis. It clarifies a changed practice stage; it does not delay reading. Reduced motion makes the state immediate.
