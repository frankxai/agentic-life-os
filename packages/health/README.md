# @frankx-ai/agentic-health-os

Biomedical and health pipeline query integrations. Serves as a gateway to the workstation's science tools:
* **dbSNP & ClinVar:** Resolves clinical significance for variant IDs.
* **ChEMBL:** Queries drug target assays and IC50 bioactivities.
* **ClinicalTrials.gov:** Searches active condition studies.
* **AlphaFold & PDB:** Maps domains and structural lookups.
