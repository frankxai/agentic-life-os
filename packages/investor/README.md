# @frankx-ai/agentic-investor-os

Descriptor-only public boundary for a separately governed private wealth
adapter. The package accepts no holdings, balances, valuations, deal names, or
financial identifiers. It performs no calculation, allocation, due diligence,
trade, recommendation, or financial advice.

Its only plan is fixed as non-executable and contains
`financialDataIncluded: false`, `adviceProvided: false`, and
`authorityStatus: 'unverified-public-plan'`.
