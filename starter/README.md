# Agentic Life OS Starter

This is a sanitized adoption guide for the Agentic Life OS practice loop. It is not a private vault and must never receive real health records, private reflections, family data, secrets, or unreleased strategy.

## The first useful loop

1. Use `/liveos today` to choose one bounded practice.
2. Use `/liveos practice` to run the session in your chosen source or personal rule of life.
3. Capture an observation and reflection in your own private workspace.
4. Use `/liveos palace` to create an evidence-linked memory anchor.
5. Use `/liveos weekly` to propose a next commitment; confirm changes yourself.

## Adoption surfaces

- **Private Next.js cockpit:** `apps/liveos`.
- **Coding-agent commands:** generate them from `packages/practice/src/liveos-registry.ts` after the `starlight-agent-config` integration lane is available.
- **Static learning page:** `starter/liveos-command-map.html`.

## Boundaries

- Health commands organize questions and records for qualified care; they never diagnose or prescribe.
- Spiritual packs retain source context and do not claim authority over a tradition.
- The current sync package is local-only. Never put raw private data into a public starter or remote demo.
